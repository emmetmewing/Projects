Predicting Baseball

Overview: This project utilizes machine learning in an attempt to predict the number of runs scored by major league baseball teams in a game. It takes historical statistics and calculates team-level features which are used in several regression models.

Features: This model uses lineup strength, opposing starting pitcher strength, opposing bullpen strength, and home vs. away status.

Models: This project uses linear regression, random forest regression, and histogram gradient boosting regression.

Results: The results are listed in the notebook provided.

Data Sources: Data was gathered using MLB statistics from the MLB-StatsAPI and Baseball Savant. CSV files with he data are not included in the repository, but information regarding the csvs and how they are used is explained in the notebook. To run this, data must be acquired from the appropriate sources.

Notes: This project served as an educational project in order for me to gain more experience with data analysis and add it to a code portfolio to showcase my skills.
