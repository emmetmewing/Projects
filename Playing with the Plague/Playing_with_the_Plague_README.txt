Playing with the Plague

Overview: This project is an investigation into the SEIR model of plagues spreading. By setting it in the historical setting of the bubonic plague, and altering variables in the SEIR model, I was able to determine which varaibles influence a plague's spread and mortaility.

Notes: This project provided me with experience working with ODEs and using them to predict how various values will change over time and was a great introduction to the concept.
