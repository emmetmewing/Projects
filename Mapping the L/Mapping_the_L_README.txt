Mapping the L

Overview: This project serves to attempt to find a relationship between the ridership of Chicago's L stations and the population of each community area. This project was a class project for a data analysis class and is one of my more beginner projects in this repository.

Methods: The methods used in this project mainly consist of calculating correlation matrices and analyzing various different ridership graphs with population based on community area.

Data Sources: The data provided was derived from the sources listed in the document, mostly Rob Paral and Associates and the Chicago Transit Authority

Notes: This project served as a general introduction and practice at coming to conclusions about data and explaining trends.
